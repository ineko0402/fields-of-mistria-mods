# Map Warp

マップで選択した解放済みの屋外地域へ、固定の安全地点にワープするMODです。

## まずこれ

- **難易度への影響：中** — 地域間の移動時間と危険を省略します。
- マップ左ページの地域名の下にある **「ここへワープ」** を押して使います。
- 確認画面で実行すると、選択地域の安全な固定到着地点へ移動します。
- 屋内、鉱山、未解放地域は対象外です。必要：MOMI 0.16.4以降。

## 導入と使い方

1. 配布ZIPをVortexなどで導入し、MOMIで **Install** を実行します。
2. ゲームでマップを開き、行きたい地域を選びます。
3. **「ここへワープ」** を押し、確認画面で実行します。

Steamの整合性チェック後は、MOMIで再度 **Install** を実行してください。

## 変更すること／しないこと

**変更すること**

- マップ画面へワープボタンを追加します。
- 解放済み屋外地域の固定到着地点へ即時移動できるようにします。

**変更しないこと**

- 地域の解放条件、クエスト、イベント、移動先の時間経過。
- 屋内、鉱山、未解放地域への移動。
- ゲーム本体やCheats Menuのデータ。

## 注意

深森・竜誓の森は、未解放の間はワープできません。マップ追加や地形変更を含むゲーム更新後は、各到着地点が安全か確認してください。

動作確認・不具合の記録は、リポジトリ直下の [COMPATIBILITY_AND_BUG_LOG.md](../../COMPATIBILITY_AND_BUG_LOG.md) を参照してください。
