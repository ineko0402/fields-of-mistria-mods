# Map Warp

マップで選択している屋外地域へワープする MOMI 用MODです。

- マップ左ページの、選択中の地域名のすぐ下に「ここへワープ」ボタンを追加します。
- 確認画面で「ワープ」を選ぶと、選択地域に設定された安全な固定到着地点へ移動します。
- 未解放の深森・竜誓の森は対象外です。
- 屋内、鉱山階層、未解放地域は対象外です。

## 注意：ゲームプレイ難易度への影響 — 中

地域間の移動時間と危険を省略します。到着地点は安全な固定位置に限定し、未解放地域・屋内・鉱山には移動できません。

## 変更すること

- マップ画面に、選択中の地域へ移動するボタンを追加します。
- 確認後、解放済み屋外地域の固定到着地点へ即時に移動します。

## 変更しないこと

- 地域の解放条件、クエスト、イベント、移動先の時間経過。
- 屋内、鉱山、未解放地域への移動。
- ゲーム本体・Cheats Menuのデータ。

動作確認・不具合の記録は、リポジトリ直下の [COMPATIBILITY_AND_BUG_LOG.md](../../COMPATIBILITY_AND_BUG_LOG.md) を参照してください。

## 導入

1. VortexでZIPを導入します。
2. MOMIで Install を実行します。
3. ゲーム内で地図を開き、行きたい地域を選択して「ここへワープ」を押します。

ゲーム本体・Cheats Menuは変更しません。

Author: mitarasi35. MOMI 0.16.4以降が必要です。
