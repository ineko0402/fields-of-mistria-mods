# Map Warp

マップで選択している屋外地域へワープする MOMI 用MODです。

- マップ左ページの、選択中の地域名のすぐ下に「ここへワープ」ボタンを追加します。
- 確認画面で「ワープ」を選ぶと、選択地域に設定された安全な固定到着地点へ移動します。
- 未解放の深森・竜誓の森は対象外です。
- 屋内、鉱山階層、未解放地域は対象外です。

## 導入

1. VortexでZIPを導入します。
2. MOMIで Install を実行します。
3. ゲーム内で地図を開き、行きたい地域を選択して「ここへワープ」を押します。

ゲーム本体・Cheats Menuは変更しません。

Author: mitarasi35. MOMI 0.14.3以降が必要です。
