# Changelog

- Declare the required `ui.menu_opened` hook so MOMI can report an incompatible game build during installation.

- Initial release.
- Adds a material-cost value to the crafting preview using normal shipping
  values rather than store purchase prices.
- Updates for the selected recipe and craft quantity.
