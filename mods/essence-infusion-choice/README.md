# Essence Infusion Choice

魔素を使って、クラフト時の追加効果を確率任せにせず選べるMODです。

## まずこれ

- **難易度への影響：高** — 狙った追加効果の道具や家具を確実に作れるため、クラフトのランダム性を大きく下げます。
- 追加効果を付けられるレシピでクラフトすると、効果選択画面を表示します。
- 「通常クラフト（抽選）」を選べば、魔素を使わず本編どおりの確率抽選にもできます。
- 必要：Fields of Mistria と MOMI 0.16.4以降。

## 導入

1. 配布ZIPをVortexなどで導入します。
2. MOMIで **Install** を実行します。
3. ゲームを起動して、クラフト台を開きます。

Steamの整合性チェック後は、MOMIで再度 **Install** を実行してください。

## 設定

初回ロード後に、次のファイルが作成されます。編集する時はゲームを完全に終了し、保存後に再起動してください。

`%LOCALAPPDATA%\FieldsOfMistria\mod_data\essence_infusion_choice\essence_infusion_choice.json`

| 設定 | 初期値 | 内容 |
| --- | --- | --- |
| `enabled` | `true` | 追加効果の選択を有効にします。`false`なら本編どおりです。 |
| `essence_cost_per_item` | `20` | 効果を指定する時の、完成品1個あたりの魔素消費量。`0`〜`999`。 |
| `show_normal_craft_option` | `true` | 「通常クラフト（抽選）」を表示します。 |

## 仕組みと制限

- 選べるのは、そのレシピで本来付与可能かつ解放条件を満たす追加効果だけです。
- まとめてクラフトする時は、選択した効果を完成品すべてへ付与します。魔素も個数分消費します。
- 候補数が多いレシピでは、選択画面が縦に長くなります。

## 変更すること／しないこと

**変更すること**

- 追加効果を選ぶ画面を追加します。
- 選択した効果を、必要な魔素を消費して付与します。

**変更しないこと**

- レシピ、素材、クラフト時間、経験値、完成品の基本性能、出荷価格。
- 本編で追加効果を付けられないアイテムや、本編の解放条件。

## 互換性

同じクラフト開始処理を変更するMODとは競合する可能性があります。併用時はセーブデータをバックアップして確認してください。

動作確認・不具合の記録は、リポジトリ直下の [COMPATIBILITY_AND_BUG_LOG.md](../../COMPATIBILITY_AND_BUG_LOG.md) を参照してください。
