# Pocket Shipping

プレイヤーインベントリのゴミ箱ボタンを、その場で売れる小さな出荷箱に変えるMODです。

## まずこれ

- **難易度への影響：中** — 出荷箱へ運ぶ手間と翌日までの待ち時間を省略します。売却は元に戻せません。
- 売却するとアイテムを即時に取り除き、通常の出荷額を所持金へ加えます。
- インベントリを開いている間、右上の所持金と `+金額` を表示します。
- 必要：Fields of Mistria と MOMI 0.16.4以降。

収納箱など、プレイヤーインベントリ以外のゴミ箱ボタンは変更しません。

## 導入と使い方

1. 配布ZIPをVortexなどで導入し、MOMIで **Install** を実行します。
2. プレイヤーインベントリを開き、売りたいアイテムをカーソルで持ちます。
3. ゴミ箱ボタンを押すと1個、Shiftを押しながらなら持っているスタック全体を即時売却します。

Steamの整合性チェック後は、MOMIで再度 **Install** を実行してください。

## 安全な動作

- 受け取る金額は、品質・考古学パークの補正を含む通常の出荷額です。
- 売却はゲームのアイテム売却記録にも加わるため、初回出荷によるレシピ解放も進みます。
- 出荷額が0のアイテムは売却・削除できません。道具などを誤って失わないための保護です。
- 即時売却は翌日の出荷箱サマリーには入りません。

## 設定

初回ロード後に、次のファイルが作成されます。編集する時はゲームを完全に終了し、保存後に再起動してください。

`%LOCALAPPDATA%\FieldsOfMistria\mod_data\pocket_shipping\pocket_shipping.json`

| 設定 | 初期値 | 内容 |
| --- | --- | --- |
| `enabled` | `true` | 即時売却を有効にします。`false`なら本編の削除ボタンに戻ります。 |
| `show_gold_feedback` | `true` | 売却後の所持金と `+金額` を表示します。 |

## 互換性

プレイヤーインベントリの同じゴミ箱ボタンやクリック処理を変更するMODとは併用しないでください。通常の収納MODとは、プレイヤーインベントリだけを変更するため基本的に両立します。

動作確認・不具合の記録は、リポジトリ直下の [COMPATIBILITY_AND_BUG_LOG.md](../../COMPATIBILITY_AND_BUG_LOG.md) を参照してください。
