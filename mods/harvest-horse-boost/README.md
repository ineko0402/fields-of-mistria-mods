# Harvest Horse Boost

ミストホースの **Harvest Horse** を使いやすくするMODです。騎乗時は広めの範囲で自動収穫・自動発掘を行い、入れない場所の入口では自動で馬から降ります。

## まずこれ

- **難易度への影響：中** — 収穫・発掘・移動に必要な操作を減らし、採集速度を上げます。
- 初期状態では、騎乗時は範囲2マス（5×5）、徒歩時は範囲1マス（3×3）です。
- 初期状態はON。専用キー操作はありません。
- 必要：Fields of Mistria と MOMI 0.14.0以降。

## 導入

1. 配布ZIPをVortexなどで導入します。
2. MOMIで **Install** を実行します。
3. ゲームを起動してセーブデータを開きます。

Steamの整合性チェック後は、MOMIで再度 **Install** を実行してください。

## できること

### 自動収穫

- 完熟した畑の作物、収穫できる低木、実が付いている果樹を対象にします。
- 未成熟の作物や実のない果樹は処理しないため、空振りで果樹を揺らしません。
- 収穫物、再収穫作物、季節イベントの限定ドロップはゲーム本来の処理に従います。

野草、岩、通常の木は対象外です。

### 自動発掘

- 騎乗中、範囲内の遺物ポイントを手持ちの道具に関係なく掘り出します。
- 遺物、発掘XP、春・秋の季節イベント限定ドロップは通常どおり得られます。
- シャベルを持っている場合だけ、シャベル品質に応じたエッセンス獲得とスタミナ消費を本編どおり適用します。

### 自動降車

騎乗のまま入れない建物・洞窟・階段などの入口へ進むと、通常の騎乗／降車切替と同じ処理で馬から降ります。その次のフレームに、本編の処理で入室します。

## 設定

最初にセーブを読み込むと、次のファイルが作成されます。編集する時はゲームを完全に終了し、保存後に再起動してください。

`%LOCALAPPDATA%\FieldsOfMistria\mod_data\harvest_horse_boost\harvest_horse_boost.json`

| 設定 | 初期値 | 内容 |
| --- | --- | --- |
| `enabled` | `true` | このMODの全機能を有効にします。 |
| `foot_radius_tiles` | `1` | 徒歩時の自動収穫範囲。0〜4マス。 |
| `mounted_radius_tiles` | `2` | 騎乗時の自動収穫・発掘範囲。0〜4マス。 |
| `harvest_fruit_bushes` | `true` | 収穫可能な低木を対象にします。 |
| `harvest_fruit_trees` | `true` | 実のある果樹を対象にします。 |
| `mounted_auto_excavation` | `true` | 騎乗中の遺物ポイント自動発掘を有効にします。 |
| `auto_dismount_indoors` | `true` | 入口で自動降車します。 |
| `debug_notifications` | `false` | 開発・確認用。徒歩／騎乗の状態通知を表示します。 |

範囲 `n` は、プレイヤーを中心とする `(2n + 1) × (2n + 1)` マスです。範囲2は5×5マスです。

## 変更しないこと

- 作物の成長速度、収穫量、果樹・低木の成熟条件。
- 遺物の出現率、発掘報酬、季節イベントの報酬内容。
- 落下アイテムの回収範囲、通常の木・岩・野草。

落下アイテムの回収範囲を変えるMOD（Polarityなど）とは別機能です。
